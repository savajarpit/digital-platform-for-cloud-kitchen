# Digital Platform for Cloud Kitchen

Monorepo for a platform serving cloud kitchens and healthy food / salad sellers.

## Structure

- [`backend/`](backend/) — NestJS API (based on a NestJS SaaS starter: auth, users, health modules, Prisma).
- `frontend/` — coming soon.

## Getting started (backend)

```bash
cd backend
npm install
cp .env.example .env.development
npm run start:dev
```

See [`backend/README.md`](backend/README.md) for details.
